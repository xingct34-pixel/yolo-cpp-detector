# CPU 本地稳定版验收

日期：2026-10-28（Asia/Shanghai）。环境：WSL Ubuntu 24.04、i5-9400、OpenCV 4.6.0、ONNX Runtime 1.21.1、GCC 13.3、CMake 3.28.3。仅 CPU，默认 ORT 3 线程。

## 功能与测试

- Release：9/9 CTest 通过。
- ASan/UBSan Debug：9/9 CTest 通过。仅覆盖本项目编译的应用/测试，不代表预编译 ORT/OpenCV 已插桩。
- 纯处理测试：RGB/CHW、padding、实际缩放还原、按类别 NMS、NaN/极大坐标、无效图像与输出形状。
- 队列测试：丢弃旧帧、关闭后排空、唤醒消费者、唤醒阻塞生产者、1000 项有序传递。
- 统计测试：无效样本忽略，超过一万帧后仍保持全程均值/极值和有界分位存储。
- 真实模型：顺序/流水线各 30 帧零丢帧；单容量 drop-oldest 计数守恒；图片推理输出 PNG/JSON；SIGINT 子进程退出码 0。
- 完整既有视频：150 帧读取、推理、输出均完成，默认阻塞策略无丢帧。

图片冒烟使用合成图像验证输入输出，不作为检测质量评测。真实视频有模型执行，但未进行标注集 mAP 评测。正常回归与取消场景分别验证，不对提前取消要求完整帧数。

## 顺序/流水线交替测量

每轮 30 帧、2 次预热、队列容量 2、headless，3 轮交替顺序。未清空 OS 缓存，未隔离全部系统后台负载；本表仅描述本次观测，不作为优化收益承诺。

|模式|各轮输出 FPS|各轮端到端 p95 ms|采样峰值 RSS MiB|
|---|---|---|---|
|sequential|3.50, 2.72, 2.60|362.50, 469.10, 491.50|228.52, 228.09, 228.91|
|pipeline|2.63, 3.34, 2.44|1987.70, 1318.62, 4244.25|249.64, 258.46, 249.03|

模型 Run、预处理、后处理、排队和消费延迟见机器可读记录。吞吐率提升不保证单帧延迟下降；当模型执行占主导、输入/输出开销较小时，流水线未必更快。没有按期望筛选掉较差结果。

端到端从读取/解码完成开始，不包含此前采集解码、加载和预热；总体阶段时间包含读取等流程。统计均值覆盖所有帧，p50/p95 超过一万帧后使用最近一万帧。比较样本少，不对尾延迟作强统计结论。
