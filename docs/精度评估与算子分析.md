# 精度评估与算子分析

当前主程序及其已有注释保留。本轮添加独立工具，不改变固定float32 `[1,3,640,640] → [1,84,8400]` 模型约定。

## 1. 从实际C++后端导出预测

准备合法取得的COCO格式bbox标注和对应图片。标注包含images（id、file_name、width、height）、categories（id、name）、annotations（image_id、category_id、bbox）。categories需要包含模型全部80类，按类别ID排序后的名称必须与data/coco.txt一致；ID允许不连续。

```bash
build-local/yolo_coco_predict annotations.json images-root models/yolo11n.onnx data/coco.txt results/fp32-predictions.json
build-local/yolo_coco_predict annotations.json images-root results/quant-experiment/model.int8.onnx data/coco.txt results/int8-predictions.json
python3 tools/evaluate_detection.py --annotations annotations.json --predictions results/fp32-predictions.json --output results/fp32-ap.json
python3 tools/evaluate_detection.py --annotations annotations.json --predictions results/int8-predictions.json --output results/int8-ap.json
```

导出器只加载一次CPU ORT模型，直接调用现有prepare_yolo/decode_yolo。为避免0.5展示阈值提前丢掉低分预测，评估导出使用0.001分数阈值；按类别NMS的IoU为0.45，保留当前整数框坐标口径。它与主程序的默认展示阈值不同，应在比较报告中一起注明。图片尺寸与标注不符、路径越出图片根目录或类别不匹配时拒绝执行。

## 2. 评估器范围

标准库实现每类、每图最多100个预测，IoU=0.50:0.05:0.95的101点插值AP，输出AP50、AP75、mAP50_95和各类别数据。没有真值的类别不进入宏平均。输入文件SHA-256一并记录。

这是明确限定的non-crowd bbox评估器，**不是完整COCOeval替代品**：不实现crowd/ignore、面积分组或segmentation；遇到crowd/ignore直接报错，不能静默忽略后再宣称官方COCO mAP。正式COCO全量结果应另用固定版本pycocotools复核。本轮不下载数据集、不把合成框测试称为真实模型精度结果。

测试覆盖完美预测、空预测、半召回、先出现高分假阳性、类别错误、IoU门槛与不支持标注。校准集与评估集须在图像内容/场景上独立；重复内容检查已有量化工具支持。

## 3. ORT算子时间线

```bash
mkdir -p results/profile
YOLO_ORT_PROFILE=results/profile/ort YOLO_ORT_GRAPH_OPT=all build-local/yolo_detector --video test.mp4 --headless --mode sequential --max-frames 16 --warmup 2 --report results/profile/run.json
python3 bench/ort_profile.py results/profile/ort_实际时间戳.json --output results/profile/operators.json
```

Profile文件由ORT在Session销毁时写出，实际文件名包含时间戳。YOLO_ORT_GRAPH_OPT支持disabled/basic/extended/all；不设置时沿用ORT默认行为。非法值拒绝启动。这里只分析真实Profile，原始文件可用于Chrome Trace兼容时间线查看器。

汇总仅计Node的kernel_time事件，按op_name与provider分别聚合；不再累计Session总计或fence，避免重复计数。算子事件dur之和不是端到端墙钟，Profile含开启期间的预热和额外开销。正式延迟比较必须关闭Profile并固定线程、输入、预热和重复次数。不能把图优化开关的存在写成已证明加速。
