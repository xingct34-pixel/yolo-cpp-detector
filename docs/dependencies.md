# 依赖与模型边界

本机验证：OpenCV 4.6.0、ONNX Runtime 1.21.1、GCC 13.3、CMake 3.28.3、Ubuntu 24.04。`dependencies.json` 记录版本及本地文件身份，不把本地哈希误称为官方发行包校验。

ONNX Runtime SDK 来自开发环境既有目录；其许可证与第三方声明原样保存在 `docs/licenses/`。SDK 本体不纳入 Git。OpenCV 使用系统既有开发环境，项目未安装软件。参考各自上游仓库的发行说明和许可证获取依赖。

当前 YOLO 权重是开发目录已有文件，已记录大小和 SHA-256 以便重现；未在本轮重新核对原始下载来源、训练数据或导出过程。不上传 ONNX/PT 权重和视频，不宣称具有模型再分发授权。取得、使用和分发模型前应遵守实际来源的条款。

TensorRT/CUDA 仅为可选实验路径，未完成当前硬件验收，不包含其 SDK。工程没有新增自动下载或系统安装行为。

本机未发现 Docker；因此未执行容器构建/运行，不将容器化声明为已验证能力。当前受支持的演示方式是 WSL CPU 本地运行。GitHub CI 仅运行无需外部 SDK 的队列与统计测试，完整视觉测试在本地执行。
