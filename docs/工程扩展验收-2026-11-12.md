# CPU精度工具与算子分析验收（2026-11-12）

> 后续进展见[小样本精度补验-2026-11-12](小样本精度补验-2026-11-12.md)；本文保留该阶段当时的验收范围。

## 已验证

- Release 12/12 CTest通过，包含已有量化预处理测试；ASan/UBSan 11/11通过，未启用可选量化Python测试项。
- non-crowd bbox评估器的4组已知答案场景通过，包括完美、空结果、半召回、高分假阳性、类别/IoU差异及非法数据；这是合成算法验收。
- C++预测导出器用现有真实FP32与INT8模型、视频首帧执行成功，分别得到134和143个预测；评估导出分数阈值为0.001。预测个数差异不能说明哪个更准确。
- ORT真实CPU Profile生成4122个事件，汇总只处理Node kernel_time。前5类算子见配套JSON；全部观测到的执行provider为CPUExecutionProvider。不能将算子事件和当成墙钟或纯硬件时间。
- 新增源文件按模块前后各两行空行分隔，保留已有解释性注释。

## 未验证

未提供独立带标注验证集，未下载数据集，未编造视频真值，所以本轮真实模型mAP、INT8精度损失和泛化能力均未验证。评估器拒绝crowd/ignore，不是完整官方COCOeval。当前精度导出沿用整数框及既有NMS。

未把Profile开启时的数据用作正式速度优化结论；未加入未经本机验收的OpenVINO、动态输入、多模型、GPU/Jetson、剪枝或蒸馏。模型身份沿用已有实验记录，不把哈希等同于证明权重来源和导出过程。
